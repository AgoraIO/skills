# Agora Cursor Plugin

Official Cursor plugin wrapper for the Agora skills repository.

## Included

- `../skills/agora/` — the canonical Agora skill pack for Conversational AI, RTC, RTM, Cloud Recording, token generation, and Agora CLI workflows
- `mcp.json` — remote MCP configuration for `https://mcp.agora.io`

## Source Of Truth

The canonical skill content lives in the repository root under `skills/agora/`.
This wrapper intentionally references that single source of truth instead of duplicating the skill bundle inside the plugin directory.
